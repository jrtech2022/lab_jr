Trilha Network Scanning (Nmap)Network Scanning Trail (Nmap)

O escaneamento de rede é a primeira fase ativa de qualquer pentest. O Nmap permite mapear dispositivos ativos, descobrir portas abertas, identificar serviços, sistemas operacionais e até detectar vulnerabilidades conhecidas. Network scanning is the first active phase of any pentest. Nmap allows you to map active devices, discover open ports, identify services, operating systems, and even detect known vulnerabilities.

ProgressoProgress 0%
Fase 1

Host Discovery (Ping Sweep)Host Discovery (Ping Sweep)

Antes de escanear portas, precisamos descobrir quais dispositivos estão ligados na rede local. O parâmetro -sn diz ao Nmap para apenas verificar se o host está ativo, sem escanear portas (muito mais rápido e silencioso). Before scanning ports, we need to discover which devices are powered on in the local network. The -sn flag tells Nmap to only check if the host is up, without scanning ports (much faster and stealthier).

Defina o alvoDefine the target
Ex: 192.168.1.100 ou 192.168.1.0/24e.g., 192.168.1.100 or 192.168.1.0/24
ComandosCommands
nmap -sn 192.168.1.100
Se você passar uma subrede inteira (ex: 192.168.1.0/24), o Nmap listará todos os IPs ativos na rede.If you pass an entire subnet (e.g., 192.168.1.0/24), Nmap will list all active IPs on the network.
Fase 2

Varredura Rápida de PortasFast Port Scanning

Por padrão, o Nmap escaneia as 1000 portas mais comuns. Para poupar tempo em reconhecimento inicial, podemos usar -F (Fast) que escaneia apenas as 100 portas mais comuns. By default, Nmap scans the 1000 most common ports. To save time during initial reconnaissance, we can use -F (Fast) which scans only the 100 most common ports.

Scan de Portas RápidoFast Port Scan
nmap -F 192.168.1.100
Fase 3

Detecção de Serviços e Sistema OperacionalService & OS Detection

Saber que uma porta está aberta não basta: precisamos saber o software exato (e sua versão) rodando nela para pesquisar exploits. Usamos -sV para detecção de versão e -O para tentar identificar o Sistema Operacional. Knowing a port is open is not enough: we need to know the exact software (and version) running on it to search for exploits. We use -sV for version detection and -O to attempt OS identification.

OS & Services
sudo nmap -sS -sV -O 192.168.1.100
Nota: A detecção de Sistema Operacional (-O) exige privilégios de administrador (sudo) porque envia pacotes customizados de baixo nível.Note: OS detection (-O) requires administrator privileges (sudo) because it sends low-level custom packets.
Fase 4

Varredura de Vulnerabilidades (NSE Scripts)Vulnerability Scan (NSE Scripts)

O Nmap possui um motor de scripts (NSE) que estende seu poder. Podemos usar a categoria de scripts vuln para varrer automaticamente o alvo em busca de falhas conhecidas como EternalBlue, vulnerabilidades web comuns, etc. Nmap has a powerful Scripting Engine (NSE). We can use the vuln category of scripts to automatically scan the target for known vulnerabilities like EternalBlue, web flaws, etc.

NSE Scan
nmap --script vuln 192.168.1.100
