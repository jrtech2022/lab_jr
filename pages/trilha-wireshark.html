Trilha Decodificação WiresharkWireshark Decryption Trail

Esta trilha ensina os conceitos práticos de captura de pacotes de dados no ar, validação do Handshake de 4 vias (EAPOL) e a descriptografia de tráfego de rede Wi-Fi usando Wireshark GUI, airdecap-ng e tshark. This trail teaches the practical concepts of capturing over-the-air data packets, validating the 4-Way Handshake (EAPOL), and decrypting Wi-Fi network traffic using Wireshark GUI, airdecap-ng, and tshark.

Fase 1

Capturando o Tráfego no ArCapturing Over-the-Air Traffic

Para decodificar o tráfego Wi-Fi, primeiro precisamos capturar os frames de dados brutos que viajam pelo ar em um arquivo do tipo .cap ou .pcap. O airodump-ng captura todo o tráfego da rede do canal e salva em disco, incluindo o handshake EAPOL necessário para a decodificação. To decode Wi-Fi traffic, we first must capture raw data frames traveling through the air into a .cap or .pcap file. airodump-ng captures all channel traffic and saves it to disk, including the required EAPOL handshake.

Dados para a capturaCapture settings
Comando de CapturaCapture Command
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:11 -w captura wlan0mon
Deixe rodando até que ocorra um Handshake EAPOL (indicado no cabeçalho superior direito do terminal do airodump-ng).Keep running until an EAPOL Handshake occurs (noted in the top right header of the airodump-ng screen).
Fase 2

Configuração de Chaves no Wireshark (GUI)Configuring Keys in Wireshark (GUI)

Por padrão, o Wireshark não consegue ler pacotes WPA2 criptografados. Ele exibirá apenas frames do tipo 802.11 Data sem conteúdo de rede IP. Para revelar o conteúdo dos pacotes, configuramos a chave e o nome da rede nas preferências globais. By default, Wireshark cannot read encrypted WPA2 packets. It will display only 802.11 Data frames without IP network payloads. To reveal packet payloads, we configure the decryption key and SSID in global preferences.

Credenciais da rede (já conhecidas)Network credentials (already known)

Instruções de Configuração no Analisador:Configuration Steps in Analyzer:

  1. Abra o arquivo gerado (ex: wireshark captura-01.cap).Open the generated file (e.g., wireshark captura-01.cap).
  2. Verifique se existe o handshake filtrando por: eapol. Sem ele, a decodificação da sessão não será possível.Check if a handshake is present by filtering: eapol. Without it, session decryption is impossible.
  3. Acesse o menu: Edit → Preferences → Protocols → IEEE 802.11.Go to: Edit → Preferences → Protocols → IEEE 802.11.
  4. Marque a caixa Enable decryption.Check Enable decryption.
  5. Clique em Decryption Keys (Edit) → Add. Selecione o tipo wpa-pwd e insira o valor no formato: {password}:{essid} (exemplo: minhasenha123:RedeLaboratorio).Click Decryption Keys (Edit) → Add. Select key type wpa-pwd and insert the key: {password}:{essid} (e.g., minhasenha123:RedeLaboratorio).
  6. Clique em OK e veja o tráfego 802.11 ser traduzido em pacotes TCP, UDP, DNS e HTTP comuns!Click OK and watch 802.11 traffic be translated to standard TCP, UDP, DNS, and HTTP packets!
Fase 3

Decodificação Automática via CLI (airdecap-ng)Automated CLI Decryption (airdecap-ng)

Se quisermos descriptografar pacotes sem abrir a interface gráfica do Wireshark, podemos usar a ferramenta airdecap-ng do pacote Aircrack-ng. Ela lê o arquivo de captura criptografado, aplica a chave, e gera um novo arquivo -dec.pcap descriptografado e pronto para análise rápida. If we want to decrypt packets without launching the Wireshark GUI, we can use airdecap-ng from the Aircrack-ng suite. It reads the encrypted capture file, applies the key, and writes a decrypted -dec.pcap file ready for analysis.

Comando de DescriptografiaDecryption Command
airdecap-ng -e "RedeLaboratorio" -p minhasenha123 captura-01.cap
O resultado será um arquivo limpo chamado captura-01-dec.cap contendo os dados descriptografados.The result will be a clean file named captura-01-dec.cap containing decrypted data.
Fase 4

Extração de Dados em Lote (tshark)Bulk Data Extraction (tshark)

O tshark é a versão por linha de comando do Wireshark. Com ele, podemos passar parâmetros de descriptografia diretamente e filtrar dados úteis do tráfego descriptografado, como requisições HTTP (caminhos, hosts visitados) ou consultas DNS em massa. tshark is the command-line version of Wireshark. It allows specifying decryption keys directly and filtering useful metadata from decrypted traffic, like HTTP requests or bulk DNS queries.

tshark CLI
Filtro de consultas DNS no tráfego descriptografado:Filter DNS queries in decrypted traffic:
tshark -r captura-01.cap -o "wlan.enable_decryption:TRUE" -o "wlan.keys:wpa-pwd:minhasenha123:RedeLaboratorio" -Y "dns.flags.response == 0" -T fields -e dns.qry.name
Filtro de URLs HTTP visitadas (caso usem HTTP sem TLS):Filter HTTP URLs visited (for unencrypted HTTP traffic):
tshark -r captura-01.cap -o "wlan.enable_decryption:TRUE" -o "wlan.keys:wpa-pwd:minhasenha123:RedeLaboratorio" -Y "http.request" -T fields -e http.host -e http.request.uri
