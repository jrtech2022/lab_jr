Trilha WPS Pin AttackWPS Pin Attack Trail

O WPS (Wi-Fi Protected Setup) tem uma vulnerabilidade no PIN de 8 dígitos que pode ser explorada com brute force. Se o roteador não bloquear tentativas, a senha é revelada em horas. WPS (Wi-Fi Protected Setup) has a vulnerability in its 8-digit PIN that can be exploited with brute force. If the router doesn't lock out attempts, the password is revealed in hours.

Fase 2

Escaneando Redes com WPSScanning WPS-Enabled Networks

O wash é uma ferramenta especializada que detecta redes com WPS ativo. Ele mostra se o WPS está bloqueado (Lck: Yes) ou aberto para ataque. wash is a specialized tool that detects WPS-enabled networks. It shows whether WPS is locked (Lck: Yes) or open for attack.

Detectar WPSDetect WPS
sudo wash -i wlan0mon
Atenção: Se a coluna Lck mostrar Yes, o roteador bloqueia tentativas de PIN. O ataque não funcionará neste caso.Warning: If the Lck column shows Yes, the router blocks PIN attempts. The attack won't work in this case.
Fase 3

Brute Force com ReaverBrute Force with Reaver

Reaver automatiza o brute force do PIN WPS. Ele testa todas as combinações possíveis (11.000 tentativas máximo) e quando encontra o PIN correto, o roteador entrega a senha WPA. Reaver automates WPS PIN brute force. It tests all possible combinations (11,000 max attempts) and when the correct PIN is found, the router reveals the WPA password.

Reaver
sudo reaver -i wlan0mon -b 00:11:22:33:44:55 -c 6 -vv
Tempo: Pode levar de 2 a 10+ horas dependendo do roteador. Use -d 2 para delay entre tentativas se houver rate-limiting.Time: Can take 2 to 10+ hours depending on the router. Use -d 2 for delay between attempts if there's rate-limiting.
Pixie Dust (ataque rápidofast attack)

Se o roteador for vulnerável ao Pixie Dust, o PIN é encontrado em segundos: If the router is vulnerable to Pixie Dust, the PIN is found in seconds:

sudo reaver -i wlan0mon -b 00:11:22:33:44:55 -c 6 -vv -K
Fase 4

Alternativa: BullyAlternative: Bully

Bully é uma alternativa ao Reaver que pode funcionar melhor em alguns roteadores. Usa uma abordagem diferente de comunicação com o WPS. Bully is a Reaver alternative that may work better on some routers. It uses a different approach to communicate with WPS.

Bully
sudo bully wlan0mon -b 00:11:22:33:44:55 -c 6 -v 3
Dica: Se Reaver não funcionar, tente Bully. Cada um tem melhor compatibilidade com diferentes chipsets de roteador.Tip: If Reaver doesn't work, try Bully. Each has better compatibility with different router chipsets.
